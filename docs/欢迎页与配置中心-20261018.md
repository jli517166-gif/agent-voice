# 欢迎页与配置中心

本轮基于 `6ff4238`，保留换机运行时重定位修复。改版前基线标签为 `baseline-before-welcome-20261018`。

## 已实现

- 原生 WinForms 开场：声线展开、声波、四模块符号汇合、AGENT VOICE 字标、欢迎页。时长约 3.4 秒，默认静音。
- 欢迎页标题“由你定调”，入口为“开始配置”“导入已有配置”“直接进入”。导入入口使用现有 `.cosyvoice.ttsmodel` / `.gpt-sovits.ttsmodel` 音色包流程，不声称恢复第三方账号或连接凭据。
- 第一帧可跳过，Esc 可跳过；减少动画直接显示欢迎页。动画结束、跳过、关闭时停止并释放计时器，欢迎页静止后不持续重绘。
- 选择入口后记录首次启动偏好，后续启动直接进入首页。关闭欢迎窗口不记录已完成，也不启动主程序。设置及配置中心允许主动重播。
- 侧边栏增加“配置中心”。环境、TTS、音色、试听、Harness 和 AIRI 都有真实操作入口，可任意跳过；支持记录和返回上次从配置中心打开的步骤。
- 配置中心资源摘要只声明文件状态。生成、播放和连接成功仍取决于原有真实验证流程。
- 偏好写入 `data/welcome.json`，独立于 `data/settings.json`，不改变音色参数、不自动启动服务、不下载、不安装连接器。

## 下一阶段边界

本轮是已批准的开场、欢迎与配置入口实现。当前配置中心调用既有环境修复、引擎定位和音色包操作。独立 TTS 包、离线环境包的新清单格式、导入与依赖解析属于后续模块化分发工作，尚未增加虚假的“安装成功”入口。没有制作新便携包，也没有修改目标机正式安装。

## 验证入口

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
& '.\dist\agent语音.exe' --welcometest '.\acceptance\welcome'
& '.\dist\agent语音.exe' --selftest '.\acceptance\ui'
& '.\dist\agent语音.exe' --scrolltest '.\acceptance\scroll'
```

`--welcometest` 验证五个分镜、三个布局尺寸、三个入口、偏好持久化、立即跳过、减少动画、关闭不提交及空白安装进入配置中心。1680×1080 画布覆盖 1.5 倍逻辑绘制，不能替代目标 Windows 系统实际 150% 缩放的人工验收。

独立观看动画可运行 `agent语音.exe --welcome-preview`；该预览不保存偏好、不启动服务，选择入口后关闭预览。正式首次启动的三个入口会进入实际页面。

设计工具记录：12ui CLI 安装出现 `spawn EINVAL`，经 `npx` 直接运行草图命令后，托管服务返回额度耗尽；没有生成可用设计候选。本轮按照用户已批准的分镜实现原生矢量绘制，使用程序真实渲染截图检查布局，未声称通过托管设计对齐。

## 本轮结果

- 普通桌面环境 Python 全量 195/195 通过，114.111 秒，包含进程树取消用例。
- Node 连接器与 DeepSeek 聊天栏控制回归通过。
- WinForms 编译通过；欢迎页自检通过（5 个帧、3 个尺寸、3 个入口，以及运行中切换减少动画）。
- 主界面 17 页、120 次切换通过。
- 68 组页面/尺寸/背景滚动检查通过，0 项错误。
- 实际截图检查 840、1120、1680 宽画布和模块汇合分镜；没有发现入口重叠、文字截断或白色异常边界。
- 没有改动 TTS 推理、模型、音色参数或运行时修复代码，因此本轮不重复 GPU 长文压力测试，也不将 UI 回归称为新的音质验收。
