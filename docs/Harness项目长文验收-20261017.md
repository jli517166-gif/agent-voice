## 修复与回归

自动朗读 Markdown 加粗句时，句末的 `**` 原先可能落成独立合成片段。现清除 Markdown 强调标记，连续句末标点与闭合引号随正文句段处理；针对已知采样空 token 引起的短输入卷积错误，按相同模型和参考进行有界重试，不更换引擎冒充成功。本轮两条长文没有触发额外重试。

## 边界与交付

单条输入原始正文仍最多 4000 字，本轮实际 Harness 正文为约 2000 与 2250 字。分段以已提交的可见消息为输入，随后按完整句播放；不表示尚未提交的每个 token 都能立即发声。仅两条项目长文和一条过程提示，不据此保证所有未来会话、硬件或超限消息均成功。
