2. 原生安装器对环境包内 **57,977 个文件**逐项校验与安装，目标 Python 路径重定位成功。
3. 将旧 `E:\App\Agent 测试`、WIP 目录移走后，三个 Python 环境仍可运行，导入路径中不含旧安装。
4. 仅保留当前软件的工具目录和 Windows 系统目录作为 PATH，开启离线限制、使用软件内缓存，再实际生成 CosyVoice、v5 Turbo、ProPlus。三项均一次成功，分别含加载耗时 43.58、42.81、25.12 秒。这不是首音延迟或其他显卡的速度承诺。

6. 配置试听连续两次真实播放与确认状态检查通过；确认由验收代码调用，仅验证流程，不代表用户已经认可音色。测试使用临时手动参考录音，未进入分发包。

8. 本轮打包／发布相关 Python 24 项通过；原生模块 21 项、配置十页三种窗口布局、网页配置与桥接单元、主界面 17 页及 120 次切换通过。新增配置顺序回归覆盖 24 次语义相同的字段重排，并保留实际修改声音后失效的检查。

## 本轮额外修复

- 安装日志不再复用固定临时文件名；使用独立临时文件，并对 Windows 短暂的共享占用有限重试。真实完整环境安装通过。
- 试听偶尔误报“配置已变化”：诊断发现声音参数、模型与录音完全相同，仅 .NET 反射导致 JSON 字段顺序变化。本轮新增规范化 JSON，再计算试听证据与比较声音草稿、模块身份；不通过绕过校验来放行。
- 增加无需软件运行时的 .NET 启动支持 ZIP。该 ZIP 普通解压到软件目录后手动运行安装器；不交给模块安装器。
- 模块入口注释改为管理扩展、引擎及运行环境，不再暗示本体自带音色归档功能。

## 用户模拟安装的边界

从《[模块化发行与模拟安装](模块化发行与模拟安装-20261022.md)》开始。软件可以先跳过配置进入空工作台；安装引擎与环境后，还需要自己的参考录音和真实试听。需要归档迁移时再单独安装扩展。

本轮通过的是当前 RTX 4050、驱动 616.92 的换目录安装，不等于全新 Windows 或其他 GPU 已验证。环境档位为 CosyVoice CUDA 12.1、GPT CUDA 12.4；其他显卡应先检查驱动与架构兼容性，再在新电脑实际生成，不能以文件安装成功代替可用性验证。

Harness 与 AIRI 需要用户在新安装分别连接和验证，本轮未将历史登录或历史绿色状态算作接入成功。已有 MCP／Harness 配置若仍指向旧路径，应在新软件内重新配置，随后重载插件或重启客户端。AIRI 保留单一原安装，默认不启用。
