# 本地数据与隐私

本版定位为 Windows 本地桌面工具。主服务只监听 `127.0.0.1`，请求需要本机连接密钥；没有开发者托管的语音生成服务。下载引擎、联网补齐环境、打开上游网页及 Harness/AIRI 自身的联网功能仍可能联网，不应表述为“永不联网”。

## 读取与播放由你控制

新安装的 Codex、DeepSeek Harness 自动朗读都关闭，配置页可主动开启。升级保留已有开关。MCP 安装自检只验证控制通路，不发送聊天消息、不生成验证语音，也不会替你开启自动朗读。用户主动调用 MCP 的朗读命令仍可使用。

开启后只接收可见的助手回复，不读取推理与工具输出。可在“设置 → 存储 → 隐私与连接”选全部已开启宿主、指定项目（含子目录）或指定会话。范围所需信息由宿主提供；信息缺失时跳过。Codex 关闭监控时不打开会话正文；重新开启不补读旧历史。DeepSeek 的会话 ID 来自连接器；项目信息是否可用取决于宿主提供的元数据，无法确认时不会默认为所有项目。可以在连接页关闭自动朗读，控制台“停止”只停止当前与排队任务。

AIRI 默认关闭，可随时切回本机输出。使用 AIRI 时，音频与相应文字会交给你选择的原 AIRI 处理；聊天记录、登录和网络提供商由 AIRI 自己管理。本软件不是 Codex、DeepSeek 或 AIRI 的官方产品。

## 本机保留位置

以下位置均相对 `agent语音.exe` 所在目录：

| 位置 | 内容与处理 |
|---|---|
| `data/settings.json` | 声音参数、参考台词、连接密钥、开关与路径；不应公开上传 |
| `data/output` | 生成音频及任务记录；默认不将正文与恢复错误写入新生成 JSON，但服务内存中保留有限任务以便重播与状态查询 |
| `data/logs` | 本软件及上游工作进程日志；上游错误可能包含台词或路径，不能当作完全脱敏材料 |
| `data/voice-assets`、`data/voice-profile-assets` | 保存声音方案时固定的参考材料与校验记录，不随音频清理删除 |
| `data/voice-rights.json` | 用户自愿记录的素材来源、用途与证据位置；不上传给开发者 |
| `data/imported-license-summaries` | 导入包附带的未经核验许可摘要，不自动变成用户自己的授权声明 |
| `data/migrations` 与其他备份 | 升级／配置备份可能保留旧正文、路径和密钥；普通清理不删除备份 |
| `tts-engines`、`voice-model-packages`、用户训练目录 | 引擎、权重、训练及用户保存文件；普通音频／日志清理不删除 |

默认生成音频按 30 分钟期限、200 MB 上限清理，每 15 分钟检查；新安装不无限保护最新几条。旧版“保留最新”行为通过独立开关保留，可手动取消。清理会跳过正在生成、播放、投递、下载或分享导出的文件。

可选择保留任务正文、关闭语音服务时清空已完成生成文件、日志保留天数（默认 7 天，0 表示不按时间清理；单个日志仍有大小轮转限制）。服务未运行时不会定时清理。关闭窗口到托盘不等于关闭服务。

“清除已存正文”只移除生成 JSON 的正文与恢复错误；“清理可删除日志”不处理模型、训练资料、证明文件或备份，Windows 正占用的日志可能跳过。音频清理不会消除音频本身包含的语音内容；需要删除声音时使用音频清理。不能承诺文件删除能抵抗磁盘取证或覆盖个人云备份。

## 诊断与撤销连接

“预览脱敏报告”采用字段白名单，只导出检查名称、类别及结果；不附原始异常详情、完整配置、连接密钥、台词、录音或模型。先在本机预览，再自行选择保存和发送，程序不自动提交。

关闭语音服务后可“撤销连接并更换密钥”：旧 Bearer 密钥失效，自动朗读和 AIRI 关闭，旧 MCP 发现回执清除。重新启动服务后重载／重新验证 MCP；AIRI 重新选择原目录接入验证。保留其登录数据、用户声音与宿主聊天。这不能阻止有权读取你本地设置文件的进程取得新密钥，也不是 Windows 用户隔离机制。

可选模块能执行代码；模型加载也可能触发其运行框架的代码能力。仅安装信任来源的模块与权重；清单哈希只证明内容一致，不证明发布者身份或软件安全。模块安装的校验与回滚不等于沙箱。
