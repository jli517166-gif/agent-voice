# 三种正式 TTS 选择的验收

范围：CosyVoice、GPT-SoVITS v5 Turbo、ProPlus。F5 与 RVC 不再作为可选输出。使用规范见《[TTS 使用手册](../TTS使用手册.md)》。

## 复验清单

- 配置 v1／v2 到 v3 的迁移保留认可声音、连接和外观，原配置有精确备份。
- 首页三个名称、模型控件与细调能力正确；多次切换不丢草稿、不叠加控件。
- 三个选择经正式 `/speak` 生成有效 WAV，版本标识正确，并实际播放。
- 声音方案保存、重启读取、MCP 列出和切换后生成均正确。
- GPT 两版本轻量包导出导入恢复参考、台词和版本；完整包只携带所选版本资源；错后缀／版本拒绝且不覆盖配置。
- CosyVoice 旧音色包继续可以导入；高级训练格式不被 GPT 冒用。
- Codex／DeepSeek 事件 API、AIRI 兼容 API、MP3 编码和停止队列继续正常。
- 更换模型后确实按选定目录读取 SV／声码器，跨版本不残留上一工作进程。
- 内置 GPT 环境路径可相对程序位置修复，共用 GPU 库仍必须保留。

## 验收边界

本机测试记录由 `acceptance/tts-integrated-20261016` 保存。真实推理、播放、单元测试和界面检查应分别记录结果；构造 Harness 事件验证不等于再次运行外部 Harness 的完整模型会话。AIRI API 音频兼容检查也不等于桌宠真机嘴型验收。未重新运行的部分不得写成已通过。

## 本次实测结果（2026-10-16）

99 项单元测试通过；15 个页面的 120 次切换通过。三种选择均完成真实生成与本机播放；MCP 切换、停止、真实 stdio 协议通过。两个 GPT 版本的轻量／完整包、重复完整导入模型复用、导入后真实推理和 C# 界面导出导入均通过；旧 CosyVoice 轻量包导入兼容。两个 GPT 版本均以 MP3 参考生成可解码 WAV、MP3，语速设置会改变时长。Codex／DeepSeek 构造事件 API 完成实际播放，未重跑外部 Harness 模型会话或 AIRI 桌宠嘴型。
