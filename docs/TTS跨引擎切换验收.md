# TTS 跨引擎切换验收

日期：2026-10-15。安装位置：`E:\App\Agent 测试`。本次以 Windows 系统 TTS（`sapi`）替换 CosyVoice 测试，不安装额外引擎或修改已有声音资产。

这是较早的系统 TTS 检查记录。之后按用户要求实际下载并新增了 Piper 适配；新引擎的结果见《[Piper 新引擎接入验收](Piper新引擎接入验收.md)》。下文描述当时的两引擎状态。

## 真实测试

统一正文为“工作好久啦，起来动一动、喝口水吧～”。

| 场景 | 结果 |
| --- | --- |
| 首页选择 `sapi`、应用并生成播放 | 完成，22050 Hz，音频约 4.69 秒 |
| 清空 CosyVoice 模型与参考条件后使用 SAPI | 完成，证明系统 TTS 不依赖 CosyVoice 的参考录音 |
| SAPI＋已有 RVC 模型 | 生成和播放完成，音频与系统 TTS 直出不同 |
| 桌面端保存声音方案 | 新建“Windows 系统 TTS · 直出测试”，独立文件夹与已保存配置一致 |
| 桌面端应用原 CosyVoice 方案并朗读 | 完成，原声音配置完全一致，未串用系统 TTS |
| 再次应用保存的 SAPI 方案 | 引擎、输出方式、参考条件、语速和高级开关与保存值一致 |
| 重新启动语音服务后用 SAPI 朗读 | 配置保留，实际播放完成 |
| 提交未适配引擎名称 | 正确拒绝，当前配置没有被覆盖 |

测试结束恢复原先的 CosyVoice 声音和 Harness 开关；保留新增 SAPI 声音方案供手动切换。没有调整模型、录音、训练权重或推理算法。

## 实际限制

这是切换到 Windows 系统声音，不是新增克隆引擎。当前支持的推理引擎只有 CosyVoice 和 SAPI；任意第三方 TTS 仍需要独立适配。SAPI 的参数可保存为声音方案，CosyVoice 音色包导入导出仍只适用于 CosyVoice。

本机从 SAPI 切回 CosyVoice 后，首次加载并完成播放约 45.53 秒，包含重新加载模型。引擎切换会释放原引擎，不能把这次冷启动耗时当作每次短句的生成速度。SAPI 直出测试中一次生成加播放约 5.62 秒，服务重启后约 10.8 秒，均为本机单次观察，未作通用性能承诺。

音频非空、任务完成和播放回执用于验证软件功能；本次没有把主观音色相似度作为验收结果，也没有将系统声音当作原克隆音色的替代训练成果。
