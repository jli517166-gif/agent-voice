# 独立配置页面与界面改版

这是 `a42d025` 阶段的记录。后续主视觉、音块、电音及时间轴已更新，当前行为见《[黑场声浪与电音界面](黑场声浪与电音界面-20261018.md)》。

本轮基线 `9cbd8a6`。用户要求重新设计软件界面，配置一步一步进行，每一步独立成页并有单独动画。本轮只调整桌面表现与导航，不改变模型、参考条件、声音参数或推理链路。

## 页面与导航

原来一个配置页中的隐藏卡片，改成八个独立路由。每个路由拥有自己的说明、滚动区域、操作和固定底部导航，不再提供步骤下拉框。

| 顺序 | 页面 | 动画 |
| --- | --- | --- |
| 1 | 从这台电脑开始 | 显示器扫描线 |
| 2 | 选一个声音引擎 | 芯片与核心脉冲 |
| 3 | 让环境就位 | 运行环境分层到位 |
| 4 | 找到你的声音 | 音色波形展开 |
| 5 | 听一听，再确认 | 扬声器声波扩展 |
| 6 | 把对话接过来 | 消息在连接端点之间传递 |
| 7 | 让桌宠接过声音 | 桌宠轮廓与对话气泡 |
| 8 | 按你的节奏开始 | 四个模块组合成结果视图 |

“下一步”前进，“上一步”返回，“跳过本步”记录跳过并前进，“保存并稍后继续”回到首页。最后一步提供“进入工作台”。从侧栏或首页重新进入配置引导，会恢复上次步骤。所有操作仍可由用户跳过，不自动下载、不自动打开 AIRI。

引擎页的“下一步”会先保存当前选择；保存出错时留在该页并显示原因。跳过引擎页不会应用新的选择。安装和连接仍由各页的明确操作触发，动画不是安装、生成或连接成功的证据。

## 动画与性能

`ui/SetupAnimation.cs` 使用原生 GDI+ 矢量绘制，无视频、网页或外部素材依赖。动画静音，约 1.8 秒后停止；只有当前配置路由可启用计时器，切页时显式停止其他七个动画。每页都有“减少动画”，设置立即作用于所有步骤并持久保存。关闭或释放控件时释放计时器和字体。

原有用户自定义等待图片和 GIF 保持在外观设置中；它们用于实际任务等待，与步骤说明动画分别管理。

## 整体界面

- 保留用户的蓝青、白、黑方向及自定义配色和整窗背景。默认使用平整背景与低对比卡片，去掉卡片和普通入口按钮的重复描边。
- 缩窄侧栏，品牌不再与图片争夺宽度；整理常用功能、声音工具与底部状态。
- 首页顶部集中服务启停、停止朗读、连接设备和配置引导。下方分别为当前声音与常用句／试听；窗口较窄时改成单列。
- 配置期间收起重复的四项状态栏，让当前步骤占据主要空间；全局状态和实际错误提示仍保留。
- 配置正文可以滚动，底部导航不跟随正文滚动；缩短了会被省略号截断的动作名称。

设计 skill 的在线草图调用因服务返回 sponsored budget exhausted 未生成图片。本轮采用原生实现并直接检查程序截图，未声称获得或对齐在线生成稿。

## 验证入口与证据

`--welcometest` 扩展验证八个独立路由、八类图形、每步三个动画帧、隐藏页面停止动画、有限时长自动停止、减少动画、进度恢复、保存选择后前进，以及跳过不应用选择。两种窗口大小下检查每页全部导航按钮都可见且不覆盖正文。

本机证据位于 `acceptance/wizard-ui-20261018/`：

- `polished/`：欢迎与逐页配置测试、八页每页三个画面和小窗口截图。
- `final-selftest/`：24 页、120 次切换的 UI 回归。
- `final-moduletest/`：14 项原生模块校验／恢复回归。
- `real-preview/`：新配置页实际启动服务、生成并播放声音、确认状态测试；独立端口，结束后关闭测试服务。
- `scroll/`：全部页面在两种尺寸、默认／自定义背景下的真实屏幕滚动采样。

模型与音色包不参与本轮变更。连接器回归仍覆盖逐步朗读与 MCP 控制；本轮没有在另一台电脑重新执行 Harness 或 AIRI 真实连接验收。

本轮结果：逐页配置与动画测试通过，24 页／120 次 UI 切换通过，14 项模块回归通过，96 组屏幕滚动采样通过；滚动报告没有背景错位或白闪错误。真实生成与播放测试通过，Node 的两个连接器测试文件通过。测试发现并修复了隐藏页计时器未停止的问题；不再依赖子控件可见事件隐式停止，统一由路由切换显式管理。
