# 交接缺口修复 · 2026-10-18

本轮停止发行打包，只处理《Agent语音-当前问题交接-20261018》列出的未覆盖项。交接文档作为问题清单使用，不把其中的操作建议当成高于用户当前要求的新指令。

## DeepSeek Harness

底层验证脚本在桌面账号无法供 `dsh headless` 使用时会返回 `manualRequired`。旧桌面程序丢弃了这个返回值，误报“Harness 已回复”，等待超时后又把已经安装的连接器关闭；因此只替换 `verify_harness.py` 不能完整修复。

当前桌面程序会读取结构化返回值。Models 中存在 API Key 时仍走全自动验证；仅有桌面账号时复制随机验证短句，要求用户在已登录的桌面 Harness 粘贴发送一次，并继续等待真实连接器事件和播放完成回执。验证未完成时连接器保持启用，界面明确显示“已安装并启用，但尚未通过”，不再回滚成未连接。

本机复测已确认自动识别 DeepSeek 安装目录、安装 desktop/headless 连接器、发现真实 `dsh.cmd`，并准确返回 `ACCOUNT_SIGN_IN_REQUIRED → manualRequired`。Windows Computer Use 当前没有返回可控制的桌面窗口，因此没有伪造最后一次桌面发送；目标机仍须在连接页面完成随机短句与实际播放闭环。

## 换机语音链路验收

系统维护页新增“运行换机语音链路验收”，也可执行 `agent语音.exe --targettest`。它使用正式服务依次加载 CosyVoice、GPT-SoVITS v5 Turbo、ProPlus，生成短句，再运行约 1000 字长文、停止任务和恢复生成，最后恢复原声音与原服务状态。报告保存到 `data/target-acceptance/latest.json`。

本机正式安装 `E:\App\Agent 测试` 的结果：三种 TTS 均成功，服务级短句耗时 3.09～3.62 秒；1026 字长文分 36 段、118.59 秒完成；停止任务状态为 `cancelled`，之后恢复生成成功。单独打开现有 `E:\App\AIRI` 后，桥接在线并完成真实播放，验证状态为 `verified`。这些结果证明当前构建在本机通过，不代替目标 RTX 5070 电脑上的同一按钮复测。

## 语速失败率

语速原先被错误归入模型切换配置，每次调整都会取消任务、关闭工作进程并重新加载；CosyVoice 的 `0.70` 还会因浮点误差越过 `-30%` 边界。两项均已修复。调整语速现在只影响之后入队任务，不中断现有任务或连接验证。正式安装完成三引擎五档 15 项矩阵及四轮 60 项压力测试，均为 100% 完成；详见《[语速可靠性修复](语速可靠性修复-20261018.md)》。

目标电脑上线本身不等于获得控制权。必须存在用户已授权并正在运行的远程执行通道，或由目标电脑用户本地执行补齐和验收，才能继续闭环。

## 音色包兼容提示

轻量音色包在只变更 torch／torchaudio／torchvision 的兼容运行时上允许导入，但旧界面没有显示 `warnings`。当前导入完成后会弹出兼容性提醒，列出运行时调整并要求立即执行环境自检和试听；不再把兼容导入静默显示为普通成功。
