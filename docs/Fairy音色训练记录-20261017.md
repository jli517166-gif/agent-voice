# Fairy 音色训练记录 · 2026-10-17

目标是还原 Fairy 的人工合成机械音色、节奏和说话方式。没有追加机器人滤镜，也不以消除机械感为优化目标。音色是否满意由用户试听确认；目前状态为待确认。

## 数据与训练

- 原素材：用户提供的 Fairy(仙子) 目录，1301 条 WAV，约 91.39 分钟，原文件未改动。
- 自动 Whisper small 转写后按时长、响度与识别置信度筛选，1196 条完成语音 token 提取。自动台词未经逐句人工校对，专有名词存在错误风险；不能称作精确人工标注。
- 按解码后重采样音频 SHA-256 去重并固定划分：训练 1080，验证 63（本轮固定取前 24 条选 checkpoint），最终保留测试 53，验证余下 39 未用于训练或本轮选优。
- 基础模型：Fun-CosyVoice3-0.5B-2512，基础 llm.pt SHA-256：`69f43bd545131c30e98947fb360ea8b4dc9916d8e83dded7757c7ea4f5a24970`。
- 训练对象：LLM 注意力 q/v 投影的 rank=8 LoRA，540672 个可训练参数；其余语言模型参数、flow 与声码器冻结。
- seed=20261017，学习率 1e-4，梯度累积 4，240 个优化步骤，bf16，保存验证最佳点并合并为普通 llm.pt。推理不需要 LoRA 特殊加载器。
- 实际基础权重没有覆盖；训练后权重变化已核对。训练脚本使用官方 CosyVoice3 前向损失，GPU 训练分配峰值约 1.014 GiB，不含其他程序占用。

## 验证

验证集损失从 3.303385 降至 2.916667。另外 53 条未参与训练或选 checkpoint 的样本，基础版测试损失 3.239382，候选版 2.888052。损失改善证明本轮权重适配有作用，不能当作音色还原度评分。

三条未见合成台词使用同一参考、同一文本和随机种子，对比未微调与候选版。CAMPPlus 对参考音频的平均说话人余弦相似度：基础版 0.8894，候选版 0.8958。自动识别仍有同音字替换，不能据此宣称每字准确；机械感、语气和习惯必须人工试听。

## 安装与复现

完整模型保存在程序 `voice-model-packages/训练输出/Fairy-CosyVoice3-20261017/`；训练报告和 LoRA 检查点保存在 `data/training-runs/Fairy-CosyVoice3-20261017/`，避免把训练中间产物当作推理模型导出。参考录音由声音方案固定保存，当前方案名为“Fairy · 机械音（待确认）”，更新前声音另存方案。

离线对照页位于程序 `data/auditions/Fairy-20261017/Fairy试听.html`，包含原录音、未微调版和候选版三组试听。此页不依赖临时网页服务器。

通用数据准备与微调工具分别为 `tools/prepare_cosy_tokens.py`、`tools/train_cosy_lora.py`，步骤见《[音色训练从零开始](../音色训练从零开始.md)》。本轮原始转写、筛选记录、token、训练计划和试听评价保存在本机验收目录，不携带进 GitHub。GitHub 不上传本地 TTS、权重或音频。

用户确认前不制作便携包，不把本轮音色标为正式验收通过。
