## 首次启动结论

**全新安装首次启动会先进入配置流程。** 本次复制软件、WebView2 SDK、前端资源和服务文件至新的测试目录，确认事前不存在 `data/settings.json`、`data/welcome.json`，也没有复制模型及 Python 环境。实际启动后窗口为“Agent Voice · 首次配置”，第一步为“让对话，在耳边发生。”。

实测点击“稍后配置”后进入控制台；保存的状态为 `onboardingComplete=false`、`onboardingDeferred=true`，没有伪造成功。再次启动进入控制台，符合主动跳过的设计；可通过设置中的配置入口继续。中途关闭且没有主动跳过时，不会标记完成。

这不适用于把开发者已经使用过的 `data/welcome.json` 一起复制给用户的情况。发布模块必须排除用户状态。缺少 WebView2 时应显示补齐／简洁配置入口，不应无声直接跳过。旧版状态的升级规则与全新安装也不同。

## 本轮修复

1. 首页常用句“管理”原先只导航到当前页，实际上没有管理功能。现增加编辑、保存、删除（删除对应行）、加入当前输入、空行清理及去重，限制 200 条、每条 4000 字。
2. 用户主动选择常用句时填入朗读正文；配置刷新不自动覆盖正在编辑的草稿。
3. 首页朗读队列由固定占位文字改为读取真实当前任务、来源、正文摘要及等待数量；断开服务显示未连接，不伪造排队状态。
4. 真实换目录测试中，CosyVoice 子进程首次绑定端口遇到 Windows `10013`。后续同端口探测可用，故不能认定存在永久端口占用。现启动前探测绑定权限及占用，必要时使用系统分配的空闲内部端口；退出错误包含日志完整路径。没有关闭其他程序来抢占端口；进程间绑定仍存在很小的竞争窗口。
5. 换机验收运行时先写 `status=running, ttsOk=null`，避免进行新验收时还显示上一轮结论；完成后写明确状态。
6. 应用任务日志及应用自有 CosyVoice 完成日志不再输出完整朗读正文。上游依赖日志和输出 JSON 仍可能包含正文，不能称为全面脱敏。
7. 补充 AIRI MIT、3dicons CC0 许可及来源说明，构建同时复制 `docs/licenses`。这不代表所有环境组件的许可审计已经完成。

## 真实 TTS 结果

设备：本机 NVIDIA RTX 4050 Laptop，6 GB 显存。所有三引擎使用隔离设置和原模型，不重新训练，不覆盖现有声音配置。运行期间未关闭用户其他 GPU 应用。

| 测试 | 实测 |
|---|---|
| CosyVoice 短句，模型加载完成后提交至任务完成 | 4.15 秒 |
| GPT-SoVITS v5 Turbo 同一句 | 4.14 秒 |
| GPT-SoVITS ProPlus 同一句 | 3.62 秒 |
| CosyVoice 长文 | 1026 字、36 段，136.86 秒生成完成，输出 203.04 秒音频 |
| 停止与恢复 | 2850 字任务收到停止后为 cancelled，之后 9 字恢复任务成功 |
| 当前 Codex MCP 真实朗读 | completed、played=true，本机输出，4.16 秒音频，一次生成成功 |
| 上述 MCP 冷启动至首声 | 55,828 ms，设备时钟估算，包含加载等待；不是温启动延迟或外部麦克风测量 |

长文测试使用 `play=false`，证明完整生成；没有据此认定这篇长文已经完整从扬声器播放。MCP 测试另有本机播放回执。短句计时不包含前面的模型加载，也不是“首声延迟”。音色还原、情绪是否满意仍需用户听审。

少量真实样本全通过不等于统计证明所有电脑生成成功率高于 95%。本次也没有证明干净电脑安装、所有网络条件、驱动版本及长期运行全部成功。建议后续在至少一台干净 Win10／11 NVIDIA 电脑完成四模块安装、三引擎实际生成、两种 Harness 随机短句及 AIRI 回执验收。
