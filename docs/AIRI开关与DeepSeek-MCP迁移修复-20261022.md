# AIRI 开关与 DeepSeek MCP 迁移修复

用户报告 AIRI“启用联动”方框被挡住，并提供 DeepSeek MCP 旧安装路径残留的交接说明。本次基于当前源码与实际安装排查，不以历史安装路径或手工协议成功代替客户端验收。

## 修复

连接页的 AIRI 标题和说明占用了开关左侧区域。缩小标签范围并为勾选框留独立空间；将此前未覆盖的连接页加入默认、缩小、最小窗口的控件重叠与裁切审计。

DeepSeek MCP 安装先检查启动文件，再备份生效配置、受管理的连接器与安装记录；任何配置、插件安装、前端校验或写入后自校验失败均回滚。readback 逐项校验 command、脚本参数、--root、cwd；failOnStartupError 改为 true。匹配 CLI 版本的已安装 MCP 客户端直接复用，避免不必要的网络下载。

主程序启动时检查既有连接：旧目录失效则重写，另一个安装仍存在时提示用户明确切换；语法损坏不自动覆盖。检查和修复无需启动语音服务，也不会改变声音设置。新增“检查 MCP”入口，状态分为配置未就绪、等待客户端、客户端已读取工具，不把文件落盘标记成真实播放验证成功。

MCP 进程记录真实 initialize 客户端名和 tools/list 回执。回执限定本安装目录、进程 ID 及进程创建身份，排除普通协议探针与死进程；不包含密钥或朗读正文。读取工具仍不等于模型侧注册成功，最终以 Harness 会话内实际调用和播放为准。

- MCP：23 项通过，覆盖插件安装／连接器复制失败、损坏写入、完整回滚、失效目录迁移、其他安装冲突、重复项、YAML 错误、进程锁、工具读取回执、缓存复用与 BOM/CRLF 语义校验。
- Harness 接入：15 项回归通过。
- 原生界面：17 页、120 次切换及 357 项子页面控件审计通过，新增连接页在三种窗口尺寸均无重叠；截图确认勾选框完整可见。
- 实际安装过程中，新增的前端字节比较曾误判 UTF-8 BOM/CRLF 差异，备份回滚生效；改回内容语义比较并新增回归后，实际安装通过。
- 正式安装的独立 MCP 完成 initialize、读取全部 8 个工具、声音方案查询、真实 read_text、状态查询、停止及关闭服务。朗读任务 generating → playing → completed，3.24 秒音频，一次生成成功；settings.json 字节未变。
- 正在运行的 DeepSeek 桌面客户端以 dsh-mcp-client 身份完成 8 个工具读取；聊天栏“查看状态”实际返回结果，保留用户未发送草稿。未发送聊天消息或把普通探针伪装为 Harness 验证，未代替用户让模型执行新一轮任务。

## 交付与维护

实际程序位置为用户选择的 EXE 目录。当前本机为 `E:\App\agent 语音服务\Agent语音`。源码位于 `E:\App\agent-voice-native-review`，分支 `integration/native-design-20261019`；共享 Git 数据位于 `E:\App\deepseek harness\项目\harness-1\agent-voice\.git`。

当前安装的替换前文件存于发行目录之外的 `AgentVoice-修复回退-20261022-MCP连接`。外部配置备份见软件 `data/connection-backups/mcp-*`。下载的依赖缓存不清理，生效文件失败时恢复；不承诺强杀进程或断电时自动恢复未完成事务。首次配置及正式手册均以当前 EXE 目录为根；旧路径只保留在历史验收记录中，不作为安装要求。

只更新软件本体分包，不重打环境、TTS 引擎和可选音色模块；私人声音与连接设置不进入发行包。MCP 仅安装 desktop，headless 保留既有自动朗读接入方式。
