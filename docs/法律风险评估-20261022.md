# Agent Voice 法律风险评估

评估日期：2026-10-22。范围：中国大陆为主要使用地区，GitHub 公开发布源码及另行分发 Windows 模块包。依据当前源码、构建脚本、本机引擎文件及官方法规和许可材料进行工程审查，不构成律师出具的法律意见，也不是发布许可证明。

后续整改：同日已取消默认声音，将全部音色包读写实现拆入主动安装的独立功能模块，首次配置不再导入音色包。下文默认 Fairy 的发现对应改版前状态；新架构见《功能模块架构与验收-20261022》。此变更降低随软件直接分发声音的风险，不替代模块使用者的声音授权，也不撤回已发布旧包。

## 结论

可以继续开发和测试。当前不能给出“所有资产均可公开发布、任意商用”的结论。最明显的发布障碍是：默认音色素材授权证据不足、项目自身尚未选择许可证、各二进制模块的许可材料不完整。公开提供在线服务时，还需要另行判断生成式 AI、深度合成、标识及可能的拟人化互动服务义务。

“用户提供”“已经训练”“人工合成机械音”“public 字段”“免费”“放在 GitHub”均不能单独证明获得了公开分发或商用授权。未发现证明不等于已经认定侵权，应补齐权利链再决定分发范围。

## 一、录音、音色与训练权重

《民法典》第一千零二十三条规定自然人声音保护参照肖像权相关规则。可识别的音色、语调和发音风格可能使 AI 合成声音关联到特定自然人。最高法公开案例也表明，获得原录音的某种使用权，并不当然包含 AI 化使用声音的授权。[民法典](https://www.cac.gov.cn/2020-06/01/c_15925617772683193.htm)、[AI 声音人格权益案例](https://legalinfo.moj.gov.cn/zhfxfzzx/fzzxyw/202506/t20250612_520815.html)。

录音还可能涉及作品著作权、表演者和录音制作者权利；合成素材同样需要追溯原录音、原工具条款和内容来源。模型权重是否构成特定受保护客体应具体分析，但权重导出不自动消除训练及使用时的权利问题。[现行著作权法](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)。

建议每个音色包记录：素材提供者、取得日期、来源、权利人、训练及克隆许可、参考音频再分发许可、权重再分发许可、商用范围、期限、撤回／投诉方式。没有确认的字段填写“待确认”，不要通过 `assetScope=public` 代替授权证据。私人测试包与公开声音包分别审核。

## 三、本地使用与公开服务的边界

《生成式人工智能服务管理暂行办法》以向境内公众提供相应服务为适用条件之一。公开源码不自动等于已运营面向公众的生成式服务，也不能笼统声称“所有 AI 项目必须备案”。若增加在线语音 API、托管推理、公众账号或具有舆论属性／社会动员能力的服务，需要专项判断。[官方办法](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)。

深度合成规定同时涉及服务提供者、技术支持者等角色；涉及人声编辑时有告知及同意等要求。应结合实际提供和分发方式判断身份及义务，不以“免费开源”一概豁免。[深度合成规定](https://www.cac.gov.cn/2022-12/11/c_1672221949354811.htm)。

2025-09-01 已施行的生成合成内容标识办法规定特定网络信息服务的显式和隐式标识，以及下载／导出等要求。当前本地 WAV 和 JSON 并未经过此项合规验收；不能宣称已经符合 GB 45438—2025。不能把所有个人离线播放一律说成必须加语音水印，也不能对外提供服务时省略适用性审查。[标识办法](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)、[官方解答](https://www.cac.gov.cn/2025-03/14/c_1743654685896173.htm)。

2026-07-15 已施行的拟人化互动办法面向向境内公众提供持续性情感互动的服务；不涉及该类互动的工作助手等被排除。单纯把 Harness 回复交给 AIRI 朗读，不能据此直接认定适用；若未来经营情感陪伴、虚拟伴侣等，则应重新评估身份提示、互动数据和未成年人保护等要求。[拟人化互动办法](https://www.cac.gov.cn/2026-04/10/c_1777558395078289.htm)。

## 四、隐私、日志和导出

聊天内容可能含个人信息、工作秘密或用户不希望留存的内容。普通录音并非当然都是生物识别敏感信息，若用于声纹识别等则需按具体用途判断。《个人信息保护法》要求在适用情形下遵守合法基础、告知、最小必要、保留期限等规则；敏感信息、跨境提供等有附加要求。自然人因个人或家庭事务处理的例外不能直接推广到发布者经营在线服务。[个人信息保护法](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)。

本次已把应用队列日志和应用自有 CosyVoice 完成日志的完整正文改为编号／字数；不追溯删除用户既有日志。仍需注意上游引擎可能输出文本，生成任务 JSON 包含正文，WAV 本身也含朗读内容。不能声称所有日志和输出都已匿名化或加密。

配置／音色导出会按包类型包含参考音频、逐字台词、权重及引擎兼容信息；部分配置导出还可能包含路径和连接设置。当前通用配置导出排除 token 和 port，但这不等于不含隐私。应提供导出内容预览、共享提醒和一键清理说明。下载引擎会访问第三方托管站点；离线推理与“程序从不联网”是不同承诺。

## 五、建议的发布门槛

1. 确认项目自身许可证和贡献来源，根目录附正式 LICENSE。
2. 默认音色取得可核验的训练、声音使用及分发授权；未完成的声音不得宣称可无条件公开商用。
3. 软件、引擎、环境、音色四类包分别附来源、版本、SHA-256、许可及权利范围；引擎和环境模块生成 SBOM。
4. 核对 FFmpeg 等二进制对应源码和许可；确认 NVIDIA／Microsoft 等再分发材料。
5. 完成数据用途、目录、保留与删除说明；故障报告脱敏；提醒公共导出会包含录音和台词。
6. 按最终运营方式核定 AI 标识、公众服务义务；在线服务上线前由熟悉中国 AI 与知识产权的律师复核。
7. 建立版权／声音权利投诉与下架渠道，记录授权撤回后软件和已分发音色包的处理办法。

本次未擅自更换项目许可证、删除声音素材、修改声音训练权重或认定特定素材侵权。需要所有者确认的权利事实已在上表标明。
