# 配置切页与卡顿修复记录 · 2026-10-19

本次按用户提供的 `Desktop 2026.10.19 - 15.37.46.01.mp4` 修复设计原型。视频约 24 秒处可见离场音色页文字与试听页主体叠加；任务页面还透出底层配置页的页头与装饰。用户桌面视频和提取帧未加入仓库。

## 原因与修复

- 原切页在动画结束前同时保留新旧 `.screen`，旧节点却立即继承新页的全局构图。改为原子替换，只对新页进行短透明度过渡，保留每页主体动画。
- 原执行任务每次推进进度都删除、重建整个弹层，重复播放入场。现在复用任务主体及图片，只更新状态内容与操作区。
- 任务界面覆盖整个窗口，拥有自己的背景；底层标题、操作栏和装饰隐藏，底层交互区设为 inert，退出时恢复。
- 布局测量按帧合并，缓存相同几何结果；删除动画结束后的重复测量，返回浏览器时不重新挂载整页。选项更新不重复播放整场动画。
- 首次显示等待本地关键图片解码与字体就绪，最多等待 300ms；空闲时只预热下一页少量图片。减少多余隐藏插画节点和大面积背景模糊。
- 发现刷新后旧工作流脚本与新布局混用。构建现在给 CSS、模块脚本添加内容哈希，并用同一 import map 统一入口与依赖的模块身份，避免缓存旧代码或重复初始化。

AIRI 页已认可的静态构图、配置步骤及选项保持不变。没有替换正式程序，也没有调用真实 TTS、Harness 或 AIRI 服务。

## 复测与接手

先在本目录执行 `python build.py`，再执行 `node --test tests/navigation-contract.test.cjs`。构建必须先于资源版本校验。静态服务器直接服务此目录即可。

正常预览使用 `index.html#setup-0`。需要诊断时使用 `index.html?diagnostics=1#setup-0`，右上角展开“渲染诊断”查看最大内容页数、任务挂载次数及切页处理耗时；正常预览不显示此面板。

响应式检查可使用 `responsive-check.html?width=390&height=800&route=setup-0&diagnostics=1`。设计交接继续通过本地 Git 与 GitHub；不向 DeepSeek Harness 会话同步。尚待用户审核视觉效果，原生 UI 中已有的未提交重构不包含在本次提交内。
