# 本轮补齐计划

本轮只改静态审核原型。上一轮配置主视觉仍待审核，本轮不视为已通过。

## 视觉约定

石墨 #121316、深黑 #08090B、冰白 #F3F5F8、辅助灰 #B0B0BC、电紫 #B7A1FF、失败提示 #FFB3A7。用户后来重新指定 AIRI 原稿，展示标题沿用宋体，操作区域为系统 UI 字体；具体构图和材质以《材质与场景修订.md》为准。

配置页继续一页一个主要决定、每页有对应动作。工作台采用声音工作室逻辑：左侧短导航，中央文本与当前声音，底部固定播放操作，队列在旁。日常页面不重复配置页的大白色插画舞台。

```text
配置：步骤标题 / 一个选择 / 单页素材 / 上一步、继续、跳过

工作台：导航 | 当前声音、文本编辑 | 朗读队列
             | 常用句             | 接入状态
             | 停止、生成并播放（固定）
```

## 补齐范围

朗读、音色包、声音方案、连接、设置、训练指南均有独立设计与可点击交互。导入、导出、保存、删除、失败重试、取消与空状态有反馈。配置补齐资源准备、离线、路径、参考音频、验证等状态，不再只打开一段占位说明。

审核原型的成功反馈必须写明“演示”，不能表示真实检测或连接通过。失败示例说明停在哪一步及下一步动作。状态演示可选择成功、失败或需手动，便于逐项审阅。

动作限制在有意义的操作后：切页约 300ms，等待条只在运行中播放，停止/离页取消计时器；减少动画后直接显示结果。音效默认关闭，遵从开关。

## 对方案的自查

不使用大卡片堆叠导航，不把每一个日常页面都套配置页斜切背景。短导航和固定停止键解决高频操作绕路；包与参数方案分开，避免“导入包”和“应用设置”含义混用。演示状态控制放在审核工具中，不冒充正式产品功能。
