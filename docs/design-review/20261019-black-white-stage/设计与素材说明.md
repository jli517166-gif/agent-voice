## 本轮范围

保留此前用户认可的文字排版和步骤转场，重做主体素材与构图。配置向导与日常工作台分离；每步单独页面，一个主要决定，始终允许跳过或稍后配置。后续补齐了日常工作台的六页独立布局与可点击状态，仍未获得用户设计通过。

配色为石墨黑、冰白和少量电紫；AIRI 保留原版粉色。采用黑色文字区与白色素材舞台，大幅实体作为视觉中心。桌面版的素材裁切跟随舞台边界，避免旋转图片的白色矩形越界；窄窗口改为上方独立插画区。

不再提供把同一套效果套到全部页面的 A/B/C 切换。各页固定素材组合和动作：

| 页面 | 主体与动作含义 |
| --- | --- |
| 开场 | 耳机舒展开场，短音阶建立声音主题 |
| 电脑 | 显示器立起，齿轮校准，扫描线经过硬件 |
| 引擎 | 齿轮啮入，文字至声音的路径展开 |
| 引擎资源 | 文件落入文件夹，表现本机资源准备 |
| 运行环境 | 工具与拼图就位，表现依赖装配 |
| 音色 | 麦克风升起，短声纹建立 |
| 试听 | 耳机轻转，独立试听声纹脉冲 |
| Harness | 对话气泡进入，消息沿路径移动；客户端标签对应选择 |
| AIRI | 本机 AIRI 原版图标入场；默认关闭，启用时才增强声纹 |
| 完成 | 拼图组合；清楚列出尚未完成的验证，不伪装成功 |

每页主体动画有限时长，支持重播、Esc 结束、减少动画及系统减少动态效果设置；离页取消动画与观察器。音效使用原型原有 WebAudio 电子合成短音，默认静音，可单独试听。

## 运行与修改

无需安装 npm 依赖。从本目录启动任意静态 HTTP 服务，例如：

```powershell
python -m http.server 51270 --bind 127.0.0.1
```

打开 `http://127.0.0.1:51270/#setup-0`。页脚下拉框可直接审阅 0–9 页及工作台；“重播本页”可重播动作，“AIRI 构图草图”打开生成草图。

修改 `art-direction.css`、`art-direction.js` 后刷新浏览器。`base-template.html` 保存本轮继承的文字、交互与转场；修改模板后运行 `python build.py` 重建 `index.html`。重建不需要开发者电脑的绝对路径或外部素材目录。

工作台代码在 `workspace.js` / `workspace.css`，执行状态在 `workflow.js`。`reviewBridge` 是原型内部的页面状态边界，不连接正式服务。`responsive-check.html` 用真正的 606×918 iframe 视口检查响应式布局；浏览器截图的外部窗口尺寸可能与 iframe 不同。
