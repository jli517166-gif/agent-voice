# 高级 CosyVoice 训练手册

> 当前引擎范围为 CosyVoice、GPT-SoVITS v5 Turbo／ProPlus。CosyVoice 训练流程仅用于 CosyVoice，GPT 不读取其训练权重；切换和音色包规范见《[TTS 使用手册](TTS使用手册.md)》。


这份手册用于有较强 NVIDIA 显卡、希望训练专属权重的用户。普通用户只需要程序里的“基础训练”指导和参考克隆。高级训练会更新模型权重，不能把一段参考音频直接改名当作训练模型。

## 1. 先确定训练目标

- 只想快速复刻音色：使用参考音频和准确台词，导出“轻量包”或“模型完整包”。
- 希望固定音色、改善长文稳定性或学习更多表达：按本手册训练权重，再导出“高级训练包”或“高级完整包”。
- 训练数据必须拥有合法使用权限。不要混入不同说话人、背景音乐、变声结果或与台词不一致的录音。

## 2. 硬件与环境

训练使用 Linux 或配置 NVIDIA CUDA 的 WSL2 独立环境；Windows 便携版是推理环境，不应在其中直接执行 Bash/NCCL 训练。显存需求随批量、长度、精度和模块变化，先试跑小批量，不能保证某个显存容量必然能完成。逐步命令、CSV 模板、清单工具和失败处理见《[音色训练从零开始](音色训练从零开始.md)》；交给 AI 时另附《[AI 训练操作约定](AI训练操作约定.md)》。

训练前固定并记录：

1. CosyVoice 源码提交版本。
2. 基础 CosyVoice3 模型名称和文件指纹。
3. Python、PyTorch、CUDA 与依赖版本。
4. 数据清单、训练参数、随机种子和 checkpoint。

agent语音会校验源码、运行环境和模型指纹，防止把权重导入不兼容的引擎。

## 3. 准备高质量数据

将同一说话人的录音切为自然短句，每段只保留一个说话人，并提供逐字一致的台词。统一采样率和声道，去除削波、长静音、强混响、噪声、背景音乐和重叠人声。

建议把数据分为训练集、验证集和最终试听集。最终试听集的句子不要参加训练。数据量增加不等于质量提高；先修正错字、漏字、噪声和异常片段，再增加录音。

按官方 recipe 生成 `wav.scp`、`text`、`utt2spk`、`spk2utt`，再生成所需的 parquet 数据列表。保留一份原始清单，方便复现实验。

## 4. 使用官方 CosyVoice3 recipe

先点击“检查训练脚本”。随程序安装的精简推理源码可能不含训练 recipe，应另行克隆完整官方仓库。以固定提交的 `examples/libritts/cosyvoice3/run.sh` 为参考，逐项完成数据加工、LLM 训练、checkpoint 选择和模型整理；不要盲目运行其中所有模块和全部阶段。基础手册给出单卡命令模板，参数仍须与实际源码的 `--help` 核对。

当前官方 recipe 支持的训练范围可能随 CosyVoice 版本变化。不要假定所有模块都能一起训练，也不要把单个 checkpoint 当成完整可推理目录。训练过程应观察训练损失、验证损失、生成样例和显存占用；出现发散、爆音或内容错误时停止并检查数据与参数。

显存不足时依次尝试：

1. 减小 batch size 和每条样本的最大长度。
2. 使用梯度累积保持有效批量。
3. 启用官方 recipe 支持的混合精度和梯度检查点。
4. 缩短单条录音，清理极端长样本。
5. 只训练官方明确支持的模块。

## 5. 整理可推理模型

训练结果必须整理成完整 CosyVoice3 模型目录。目录至少包含：

```text
cosyvoice3.yaml
llm.pt
flow.pt
hift.pt
campplus.onnx
speech_tokenizer_v3.onnx
CosyVoice-BlankEN/
```

使用与训练时相同的基础模型和配置文件，把训练后选定或平均后的权重放入该目录。先用 CosyVoice 自带推理示例确认能加载，再在 agent语音“基础训练”页面选择并校验目录。

## 6. 验收声音

至少覆盖以下试听：

- 未参加训练的短句、长段落、数字、英文和标点。
- 平静、温柔、活泼等目标表达。
- 连续多句生成，检查音色漂移、吞字、重复、异常停顿和噪声。
- 与基础模型对照，确认训练确实带来改善。

必要时记录 ASR 字错率、说话人相似度和人工评分。指标只能辅助判断，最终仍要听未见文本的实际输出。

## 7. 选择导出类型

程序的“音色包”页面提供四种明确标准：

| 类型 | 包含内容 | 目标电脑要求 | 适合场景 |
| --- | --- | --- | --- |
| 轻量包 | 参考音频、台词、参数和模型指纹 | 已有完全相同的基础模型与环境 | 同环境快速迁移参考克隆 |
| 模型完整包 | 上述内容加当前基础模型 | 需要匹配的 CosyVoice 源码和 Python 环境 | 离线迁移参考克隆 |
| 高级训练包 | 训练后相对基础模型变化的权重和完整指纹 | 已有完全相同的基础模型与环境 | 节省空间地迁移训练成果 |
| 高级完整包 | 完整训练模型、参考条件和指纹 | 需要匹配的 CosyVoice 源码和 Python 环境 | 跨电脑迁移完整训练模型 |

高级完整包包含训练后的模型目录，但仍不包含 CosyVoice 源码、Python、CUDA 或 RVC。它不需要把整套 TTS 引擎一起导出。只有在源码或运行依赖也不同的情况下，才需要按《安装手册》单独安装匹配的引擎环境。

导入前先停止语音服务。程序会在写入配置前校验包内哈希、模型结构、源码指纹和运行环境指纹；校验失败时不会覆盖当前声音。

核心运行环境、状态和恢复步骤更新见《[稳定性与故障排查](稳定性与故障排查.md)》。训练入口仍为指导流程；新音色包忽略 Python 注释／格式和 Markdown 差异，运行代码、模型和推理依赖继续校验。

## 小显存微调工具

仓库提供 `tools/train_cosy_lora.py`，基于兼容 CosyVoice3 官方前向损失，只训练注意力 q/v 投影的 LoRA，冻结声学 flow 与声码器。需要预先准备带 text_token、speech_token、instruct_token、sha256、split 字段的 JSONL，并严格按音频去重划分 train/dev/test。默认 seed=20261017、rank=8、学习率 1e-4、梯度累积 4、240 步。输出目录必须全新；仅当验证损失改善时才保存合并 llm.pt，原始基础模型不改写。输出报告记录权重变化、基础模型指纹和验证轨迹。

这是已在 Fairy 本机实验中使用的专门工具，不等于一键训练所有版本；没有覆盖官方全量训练的能力。自动转写必须标注未人工逐句校对，含专有名词的错误不能当作准确台词。机械合成声的验收应保留参考的节奏与合成质感，不套用“越像真人越好”的目标。训练输出必须补齐其余原始模型文件，再用未见文本试听，用户确认后才切换发行默认。
