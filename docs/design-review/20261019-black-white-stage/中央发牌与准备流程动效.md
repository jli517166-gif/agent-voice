本轮为浏览器设计审核稿，配置步骤和配置项不变，仍待用户审核。未部署正式程序，不执行下载、环境安装、TTS 或外部连接。

## 设计实现

- 共用画面中心为起点。每次入场先一次性读取各元素最终布局，再只以 transform / opacity 将文字、操作卡片和插画发往各自落点。标题词组最先出场，说明、控件、插画依次错开，强调线覆盖完整标题。
- 标题容器尺寸不随动画变化。移除原文字遮罩，避免飞出中心的字形被局部容器截断。AIRI 保留原构图、图标、粉色强调和曲面材质，开关行也参与共享入场。
- 准备引擎任务增加展开的文件层、执行中的文件传递、阶段进度和完成回执；补齐环境任务增加 Python / GPU / 依赖模块、逐项点亮及完成标记。两种执行视觉分开。
- 任务页仅首次打开或阶段改变时编排入场；执行中的状态在原 DOM 上更新，避免进度刷新打断入场或重新排版。演示执行阶段在 1.1 / 2.2 秒推进，3.6 秒给出结果；这些时间是视觉审核样例，不是下载或安装耗时。
- 执行中的取消按钮保持固定位置，立即可用。返回、取消和切页清理旧动画、定时器及弹层；减少动画模式关闭发牌与循环效果。Esc 在任务入场时先结束入场，再次按下返回；无入场时直接返回。
- 普通预览无诊断面板；仅 `?diagnostics=1` 提供真实动画时间轴控件，用于逐帧审核。
