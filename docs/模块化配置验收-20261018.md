## 验证边界

- 上述真实离线包只含主服务与 FFmpeg，不含任一 TTS GPU 环境；不能据此宣称所有 CUDA 档位和干净目标电脑均已验收。完整引擎与 GPU 环境包的真实大文件发布仍须在对应硬件联合验收。
- 本轮没有修改推理音色参数、模型权重或播放队列算法。真实试听是播放路径验收，不代表用户已认可声音；自动测试对确认按钮的调用只验证状态机。
- Harness 和 AIRI 使用已有的随机挑战、来源回执和播放确认，未用模拟状态充当本次外部会话成功。本轮未在另一台电脑重新登录并端到端验证这两类连接。DeepSeek 桌面登录的手动短句步骤保留。
- 模块档位和最低驱动为制作方声明；原生安装校验文件，不自动安装驱动、不替代实际 CUDA 推理。外部自建 Python 环境不保证可直接复制迁移。
- 严格离线禁止下载与远程 pip 回退；不会自动凑齐未提供的 wheel。系统级驱动、VC++、.NET 仍需用户按缺项安装。
- 本轮未制作新的完整发行包，未修改另一台电脑的正式安装。

## 维护入口

`--welcometest`、`--moduletest`、`--selftest`、`--scrolltest` 接收验收报告目录。真实测试 `--setupvoicetest`、`--bundletest` 必须使用独立配置和端口；前者会实际发声，后者会写音色资源。不要对日常安装直接运行有状态验收。

模块文件格式版本为 1。制作在 `tools/module_packages.py`，原生安装在 `ui/ModulePackages.cs`，配置流程在 `ui/SetupPage.cs`。设置只允许模块拥有的引擎路径，安装日志与恢复文件统一位于软件的 `data/module-install` 与 `data/module-backups`。
