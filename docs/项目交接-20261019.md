## 3. 用户最新核心目标与决定

用户对软件的五个核心目标是：**装得上、说得像、同步稳、简洁、高度自定义**。

已经确定的产品方向：

1. 本地 TTS 是主输出，RVC 变声已退出正式功能，不应恢复旧 RVC 路线。
2. 当前源码引擎注册表为 CosyVoice，以及 GPT-SoVITS 的 v5 Turbo / ProPlus 两个变体。虽然历史上试听过 F5、Chatterbox、Qwen、MOSS 等，不能因为旧聊天提到就重新列成当前支持项。以 `service/engine-catalog.json` 为准。
3. 首次配置与日常软件是两个阶段：像新电脑首次开机一样，每步单独页面，允许跳过或以后补齐。可以什么都不装直接进入本体，但不得宣称此时已能朗读。
4. 发行改为四类独立模块：**软件本体包、TTS 引擎包、环境补齐包、音色包**。离线环境包解决网络差的电脑无法下载依赖的问题；不能强制用户一次下载全部组件。
5. 目前正式只承诺经实际验证的 **Codex、DeepSeek Harness**。其他客户端留适配开发入口与说明，不做未经实测的“一切 Harness 自动接入”承诺。
6. Codex 用原生技能入口与 MCP 语言命令；没有定制聊天栏常驻按钮，没有桌面浮窗，也未接管 Codex 内置朗读。DeepSeek 有聊天输入栏语音按钮及播放动效；两者不能混写。
7. AIRI 为可选，默认关闭；使用用户已有且已登录的原安装，不复制生成第二套 AIRI。不启用时本机扬声器正常播放。桥接可能受 AIRI 更新影响，修复后仍需真实播放回执验证。
8. 导入导出音色包与引擎、环境包分开。音色包携带引擎标记，轻量与完整／高级包按已有契约处理，不能“只改后缀强行匹配”。
9. 最近确认的便携默认声音为 **Fairy（仙子）**，需保留其人工合成机械音特点；小挽昼、个人外观和其他私人声音资源不得随意进入公开发行。当前用户已要求暂停，不开始新打包或清理。
