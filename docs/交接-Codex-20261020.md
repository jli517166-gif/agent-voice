现象（1610×1006 最大化）：

- 页面深色画布只覆盖窗口中间一块，左右/底部露出桌面或用户背景图；
- 标题、卡片、按钮看起来像“透明/悬浮”，实际是根容器没有铺满客户区；
- 标题和部分文字被裁切或压在卡片下；
- 默认 1180×800 基本正常，最大化后明显。

已尝试但未解决：

- `WebFit` 按 978×604 基准缩放，限制 1.4/1.5；
- 主页/侧栏加深色遮罩、标题不透明背景；
- 截断长音色名、加宽按钮；
- 直接给网页页面铺深色背景。

1. 最大化后 `ClientSize` / DPI 缩放与 `shell`、`outer` 根容器尺寸不一致；
2. `shell`/`outer` 没有真正随客户区铺满；
3. 绝对坐标页面按固定 978 宽设计，未按客户区重新排。

3. 不要再用遮罩/固定缩放补；把 `shell`/`outer` 改为真正填满客户区，网页页面按可用宽度重排；
