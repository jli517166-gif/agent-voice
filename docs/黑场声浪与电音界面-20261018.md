# 黑场声浪与电音界面

基线 `a42d025`。用户明确选择黑场声浪，随后补充简约赛博朋克、音块声浪与对应电音音效。本轮是桌面软件的实际界面改版，不是独立 PPT 文件。

## 设计来源与规则

按用户要求下载安装并阅读：

- [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)：先建立主体、排版、配色与构图，再对照真实截图检查。
- [Frontend Slides](https://github.com/zarazhangrui/frontend-slides)：以大字、低信息密度、分镜、材料视觉和有限节奏构成发布会感。三种 16:9 动态参考由用户选定黑场方案；桌面操作区仍按真实窗口布局，避免把按钮和文字缩成不可用的 PPT 缩略图。

设计规则是：黑场 `#000000`；青蓝 `#19C7F2`；电蓝 `#0B55E7`；雾白 `#EAF6FF`；操作面板 `#101A25`；辅助文字 `#93A8BC`。正文和按钮继续使用可读的 Windows 中文字体，主视觉标题 32～56 px，品牌使用 Bahnschrift。保留用户自定义背景和配色。

## 软件中的改动

- 开场和首页使用新生成的玻璃／金属声浪与音块频谱，文案和按钮由程序绘制，未烘焙进图片。
- 八步配置分别为独立路由。配置时收起侧栏与重复顶栏，左侧为大字与场景，右侧为真实操作，底部始终可返回、继续、跳过、保存。
- 八个场景分别为电脑、引擎阵列、环境堆栈、声音雕塑、试听声浪、双端连接、桌宠对话球、模块组合。音块和短暂节拍运动统一风格，未用假进度或成功标识替代检查。
- 动画约 2.8 秒后停止，离页立即停表；用户无需等动画结束即可操作。“减少动画”独立保存，立即显示最终状态。
- 九个原创短电音由标准库合成，未安装额外运行环境或音频编辑器。开场与页面操作可使用对应提示音；测试模式、音效关闭和检测到语音服务监听时不播放新的界面音效。等待／朗读操作会停止先前提示音，避免和声音试听混在一起。
- 电音开关位于配置页底部及设置 → 外观，立即同步并保存到 `data/welcome.json`，不进入音色包。

## 模块与维护

`SetupAnimation.cs` 管理标题与有限时间轴，`KeynoteArt.cs` 负责图像和大幅原生场景，`InterfaceSounds.cs` 管理异步 WAV 加载和替换播放；公共素材只加载一份并在释放窗口时释放。声音生成服务、模型、参考录音和已保存音色参数不参与此次变更。

视觉素材位于 `assets/keynote-voice.png`，提示音位于 `assets/sfx`，来源与重现方法见 [素材说明](../assets/README.md)。软件本体模块显式允许九个原创提示音；其余用户录音仍排除。

本机证据保存在 `acceptance/keynote-cyber`。声音演示 `interface-sound-demo.wav` 将九个短音效按顺序连接，供听感检查；它不是 TTS 音色。
