# 工程检查与实机验收 · 2026-10-16

本轮在独立安装目录中复用同一份模型二进制，使用独立设置和端口；当前认可版的模型、参考音频与声音参数不作调整。实机为 Windows、RTX 4050 Laptop GPU，结果不能直接代表其他显卡、驱动与 Harness 版本。

## 已修复

- 同一音色包反复导入、轻量与完整包切换或改文件名，按内容指纹复用参考资源；不同模型仍严格校验。
- 主服务、离线保存和音色包操作使用跨进程文件锁，防止并行写配置；保留原子替换和失败回滚。
- 区分端口没有监听、服务未响应以及另一安装目录占用端口；超时不再被误认为可以离线改写配置。
- 正常关闭时不再向正在退出的 HTTP 服务轮询，等待后台资源释放后才保存配置；超时清理只针对本程序拥有的进程树。
- 推理适配器在关闭、文件移动与状态查询并发时的空引用／文件状态竞态。
- 服务、工作进程日志轮换；日志写入失败不再递归写回 stderr，日志管道初始化失败也会清理工作进程。
- Harness 验证超时会清理本次启动的命令进程及子进程。
- DeepSeek 按钮改用原生 RPC 调 MCP，避免把原始 JSON 加进聊天记录；空闲状态明确标为“空闲”。前后端升级后要完整重启客户端。
- 匿名健康检查不再暴露朗读正文、验证短句或本机路径；详细状态仍使用本机密钥。
- 修复滚动测试仍引用已删除页面的问题；更新构建过程，避免重复嵌套插件目录。
- 新增训练素材检查、确定性划分与 Kaldi 清单生成；明确拒绝含空格的训练输出路径，避免官方读取器截断路径。
- AIRI 嘴型探针的截图失败不再阻断参数报告；桥接安装器变更也参与更新判断。

## 首声与冷启动

以下首声来自 Windows 输出设备启动时刻估算，包含任务等待与生成；不是麦克风回录测量，也不是纯模型推理基准。

| 引擎 | 热态短句首声 | 本轮冷状态 |
| --- | --- | --- |
| CosyVoice | 约 5.7～7.0 秒 | 服务冷准备约 35.7 秒，之后首句首声约 6.7 秒 |
| GPT v5 Turbo | 约 2.36～2.50 秒 | 切换后首句含加载，首声约 47.8 秒 |
| GPT ProPlus | 约 2.08～2.11 秒 | 切换后首句含加载，首声约 30.6 秒 |

CosyVoice 取消返回约 0.42 秒。为中断正在进行的推理，工作进程可能被释放，下一次生成需要重新加载；本轮取消后的下一条首声约 43.7 秒。停止快速不等于停止后的下一条仍是热态。

长文的总耗时比音频时长多约 65 秒，包含首声、等待、设备切换和拼接。当前 CosyVoice 推理速度不能保证逐句无间隙播放，不能宣称零延迟。此轮没有为提高速度更改认可版权重、参考条件或推理采样参数。

## 内容复核与未覆盖范围

用独立 faster-whisper small CPU/int8 复核四份输出，统一简繁、大小写并去标点。短句／长文／两个 GPT 段落的识别差异率约为 7.1%、8.3%、3.0%、6.1%。这是辅助 ASR 的差异，不等于 TTS 的真实字错率；同音字、语气词和长文重复段落均可能影响识别。生成完成与元数据正文一致，不能代替人耳确认音色、错读、吞字与自然度，需结合保留音频试听。

本轮独立安装使用已有完整环境和模型迁移，验证了目录重定位、独立依赖、空目录导入及真实发声；没有把它说成一台全新 Windows 上从互联网重装所有依赖的验收。源码版手动安装仍须逐项完成《安装手册》的 CUDA、模型、Python 与播放自检；下载新版上游可能与旧音色包的严格指纹不一致。

真实权重训练未在本轮执行；素材检查通过也不代表训练效果通过。程序推理环境缺少训练 recipe 时，需要独立 Linux／WSL 完整训练仓库。用户步骤见《[音色训练从零开始](../音色训练从零开始.md)》，交给 AI 时附《[AI训练操作约定](../AI训练操作约定.md)》。训练硬件、指令版本与最终真人试听需要在实际训练环境继续确认。

其他电脑的驱动、音频设备、外部账户与 Harness／AIRI 更新，均需要在目标机器重做真实挑战和播放回执验证。当前正式适配仍限 Codex、DeepSeek 和指定版本 AIRI。

本机原始证据位于开发目录 `acceptance/release-audit-20261016`，包含过程记录、时延、真实模型导入和测试音频；不随源码上传个人设置、账号或录音。

补充发现：当前长时间运行的 Codex 聊天还驻留旧 MCP 进程，启动工具仍读旧 `pythonRvc` 字段。插件与独立核心环境入口已更新到 1.5.0；旧连接需要重载，当前聊天的连接尚不算通过。用户选择稍后重载，正式目录另用新进程验收。自动朗读连接器与 MCP 控制连接是两个独立通道，不能互相替代验收。
