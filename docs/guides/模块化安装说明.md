# Agent Voice 模块化安装说明

这一套发布文件分为软件本体、离线运行环境和 TTS 引擎。它不包含默认音色、用户录音、训练音色包，也不包含音色包导入导出模块。

## 第一次在新电脑安装

1. 打开 `02-运行环境/首次启动支持`，右键以 PowerShell 运行 `检查并安装系统组件.ps1` 先检查。需要补齐时，在该目录打开管理员 PowerShell，执行：
   `PowerShell -ExecutionPolicy Bypass -File ".\检查并安装系统组件.ps1" -InstallSystemComponents`
2. 按检查结果安装或更新 NVIDIA 显卡驱动。驱动与显卡型号有关，不随本包提供；本环境包最低要求以 `包清单.json` 为准。
3. 解压 `01-软件本体` 中的 ZIP。不要只复制 EXE，也不要在 ZIP 内直接运行。
4. 启动软件，按配置流程选择需要的 TTS 引擎。软件没有附带声音，之后需使用你有权使用的参考材料或训练结果。
5. 在“准备引擎”页面导入 `03-TTS引擎` 中对应的 `.ttsengine`。可以安装一个或多个引擎。
6. 在“补齐环境”页面导入 `02-运行环境` 中的 `.ttsenvironment`。
7. 点击“检查已有环境”。只有检查通过并完成一次实际生成、播放验证，才算安装完成。

环境包只补齐 Python 运行时、依赖、FFmpeg 等本地环境，不包含 TTS 源码和基础模型；引擎包提供对应源码和基础模型，但不替代运行环境。两个包都导入不代表声音配置已经完成。

## 进度、失败和恢复

导入大包时会显示已处理字节、总字节和百分比。进入“正在应用模块”阶段后不要强制结束软件；安装失败会自动恢复原文件。若提示服务或安装操作正在运行，先从托盘退出 Agent Voice，再重新导入。

驱动版本低于环境包要求时，软件会在写入文件前停止并明确提示。系统组件安装器返回需要重启时，应先重启 Windows，再重新运行检查脚本。

## 文件职责

- `01-软件本体`：桌面程序、配置流程、MCP 控制与说明。
- `02-运行环境`：双引擎离线依赖与首次启动系统组件。
- `03-TTS引擎`：CosyVoice、GPT-SoVITS 的源码与基础模型，按需导入。
- `审计资料`：构建时从软件本体排除的开发审计记录，不参与运行。
- `包清单.json`：版本、最低驱动要求、文件大小和 SHA-256。

若只需要其中一个 TTS，引擎包可只导入对应的一份；双引擎离线环境包含两套运行依赖，便于之后快速切换。
