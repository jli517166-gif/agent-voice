# 环境检查与补齐

环境检查应覆盖主服务 Python、FFmpeg、引擎源码、基础模型和引擎 Python 依赖。文件存在、模块能导入与实际推理成功是不同结果。

## 使用

在设置或配置流程中选择引擎，检查缺项，再按结果准备资源与依赖。网络不可用时使用匹配的离线资源；严格离线模式不调用远端下载或 pip 索引。

安装文件保存在应用自己的目录。外部 Python 可定位使用，但修复不应改写不属于应用的环境。健康环境不强制升级；更新引擎或模型前保留已验证版本。

默认目录和独立环境关系见 [安装手册](安装手册.md)。系统组件包括 .NET Framework、WebView2、VC++ 运行库，显卡驱动按硬件单独处理。

## 验收

1. 核对版本、路径、依赖与 GPU 可用性。
2. 加载当前选择的模型和参考条件。
3. 生成短句并检查有效音频。
4. 测试播放、长文、停止、恢复和跨引擎切换。

换电脑后在目标机器重新执行。Harness 与 AIRI 连接不由本机 TTS 检查代替，另按 [接入说明](接入说明.md)验证。

失败时保留具体组件、命令退出结果和脱敏日志。校验失败先重新取得文件，缺失依赖按固定版本修复，显存不足先停止其他推理任务；不要静默换引擎掩盖错误。


## 下载可靠性与重试

PyTorch 官方 Windows 轮子按 Python 与 CUDA 版本精确匹配，支持分段续传、下载速率反馈和最终 SHA-256 校验。中断分片位于 `data/environment-repair/wheels/`，重试时保留。普通源码和引导文件仍按各自下载校验流程处理，不保证所有地址支持断点续传。

模型下载固定 revision，使用稳定暂存位置和有限重试。Windows 使用系统信任链而不关闭证书校验；系统时间、网络代理或受信任根证书异常仍需使用者修复。失败原始信息位于 `data/environment-repair/install.log`，请先脱敏再提交。

软件自身更新见 [下载与首次使用](../../下载与首次使用.md)，软件更新不会替代 TTS 引擎和环境补齐。


## 暂停与继续下载

配置向导下载引擎、补齐环境，以及设置中的软件下载任务执行时，会显示“暂停下载 / 继续下载”和“停止下载”。暂停后不会把任务标为完成；继续使用当前任务和已下载数据。暂停时间不计入下载子任务的执行限时。

暂停需要等当前网络读取返回；正在执行的安装或解压会先到达安全边界，不强行冻结安装过程。点击停止后等待任务退出，再关闭窗口。下次重新点击同一下载入口，会复用已完成文件以及模型、Torch、带哈希运行时文件的可续传断点。部分不支持续传的小型源码归档会重新获取。

软件更新同样支持暂停和停止；完整哈希与逐文件校验通过前不会安装更新。若显示“正在暂停”，说明尚在等待当前数据块或安装步骤结束，不能当作已经停止传输。
