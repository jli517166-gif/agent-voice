# 独立唱歌功能

Agent 唱歌与 Agent Voice 的 TTS 分开运行。TTS 负责把 Harness 正文读出来；唱歌软件负责歌词、音乐风格、歌曲任务和歌曲文件。两者不会共用模型目录，也不会把唱歌模型写进声音方案。

## 安装与目录

1. 在“模块”页导入 `Agent唱歌-*.avmodule`。
2. 再导入受支持的 `*.singengine`，目前实测适配 ACE-Step 1.5。
3. 唱歌软件位于 `modules/agent-singing/module.exe`，引擎位于 `singing-engines/<引擎 id>`。
4. 生成任务和默认输出位于 `data/singing`；可在唱歌工作台中把歌曲保存位置改到其他目录。

软件本体、唱歌工作台和唱歌引擎分别打包。不安装唱歌模块不会影响朗读、Harness、AIRI 或 TTS。

## 使用

从 Agent Voice 左侧点击“唱歌”，选择已安装引擎，填写风格与歌词，再提交生成。任务在后台运行，工作台会显示完成或失败以及输出位置。首次启动 ACE-Step 通常需要加载模型，耗时明显长于后续任务。

DeepSeek Harness 安装最新版 MCP 后，聊天栏“语音”菜单提供“打开唱歌”；语言命令还可列出／切换唱歌引擎、提交歌词、查询任务和修改输出目录。提交成功只表示进入歌曲队列，不表示已经生成完成。

## DeepSeek 桌宠语音

连接器使用 dsh-pet 官方公开的 `petApi7340.voice.register` 扩展接口，把 Agent Voice 当前声音注册为桌宠的外部语音提供方。需要同时满足：DeepSeek Harness 已重载连接器、dsh-pet 宿主插件已启用、Agent Voice 服务已启动、当前 TTS 能在桌宠规定的 15 秒内生成。

反向使用时，在 Agent Voice 的“声音设置”中选择 `dsh-pet · 当前音色`，填写桌宠 Web 地址，格式为 `http://127.0.0.1:<端口>/dsh-pet-7340`。官方默认端口通常是 3080，实际端口以 DSH Web 服务显示的地址为准。音色 ID 可留空使用桌宠默认声音；填入时必须是桌宠 `/voice/voices` 返回的 ID。Agent Voice 会通过官方 `/voice/speak` 取得 MP3，再用自己的 FFmpeg 转成 WAV 进入现有朗读队列。此模式不需要 Agent Voice 的本地 TTS 权重和参考录音，但需要桌宠宿主的语音服务真实在线。

两个方向的语音提供者不能互相调用：选用 dsh-pet 引擎时，连接器会停用“Agent Voice 当前声音”的桌宠注册；切回本地 TTS 后再恢复注册。如果插件版本不提供上述官方接口，程序会显示连接或音色列表错误，不会假装成功。

该兼容层不复制 dsh-pet 的角色、动画、声音或其他素材。桌宠更新改变接口时，应重新安装连接器并复验；失败会明确报错，不会静默回退到另一种声音。

## 许可与内容

只使用你有权处理的歌词、旋律、录音、角色声音和模型。ACE-Step 源码许可不自动覆盖模型权重、训练数据、歌曲版权、表演权、声音人格或生成内容的发布用途。发布歌曲前应按实际来源和用途分别核对。
