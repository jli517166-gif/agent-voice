# 模块化发行与模拟安装

本次发行把软件本体、离线环境、TTS 引擎与可选功能模块分开提供。不附带默认音色、个人录音、训练结果、外观配置或已验证的连接状态。GitHub 仅同步源码、制作工具和说明，不上传运行环境或模型大文件。

## 四类文件

| 目录 | 文件 | 安装方式 |
| --- | --- | --- |
| 01-软件本体 | `AgentVoice-软件本体-20261022.zip` | 完整解压，运行其中的 `Agent语音/agent语音.exe` |
| 02-离线环境 | `.ttsenvironment` | 在配置流程或“模块 → 导入模块”选择文件 |
| 03-TTS引擎 | 两个 `.ttsengine` | 按需安装 CosyVoice3、GPT-SoVITS，允许都装 |
| 04-可选模块 | `.avmodule` | 按需安装；音色包导入导出不是本体发声的前提 |

GPT-SoVITS 的 v5 Turbo 与 ProPlus 共用一个引擎包和运行环境，软件内分别选择；不需要两份安装。引擎包包含通用基础权重，不包含为本机角色训练的音色权重。环境包包含主服务 Python、两个引擎的 Python 依赖、GPU 运行库和 FFmpeg，不重复放基础模型。

## 从空目录开始

1. 将软件本体 ZIP 解压到自己有写权限的新目录，保留全部文件，不要只复制 EXE。不从旧版复制 `data`、`voices`、`voice-model-packages` 或整个安装目录。
2. 启动 EXE，首次进入独立配置流程。可以跳过全部选项进入空工作台，再从“设置 → 配置流程”继续。跳过不代表声音已可用。
3. 选择需要的 TTS。网络不佳时，在引擎准备页面导入对应 `.ttsengine`；安装多个时逐个导入。拥有本地包就不必再次下载。
4. 在运行依赖页面导入 `.ttsenvironment`。也可先进入工作台，从“模块 → 导入模块”安装资源包。原生安装不要求预先装 Python，不执行 pip，不连接网络。
5. 若缺 WebView2，可用原生配置继续；环境包内 `tools/system-prerequisites/webview2/` 提供微软 x64 完整离线安装器。缺 VC++ 时运行同级官方安装文件。系统组件由用户按提示安装，不静默提权；NVIDIA 显卡驱动必须按本机硬件单独安装。
6. 手动选择自己有权使用的参考录音、填写相应台词，使用引擎基础模型或自己的训练模型，实际试听。没有默认音色，因此未选参考素材时不能直接生成克隆声音。
7. 默认输出本机扬声器。选择 Codex 或 DeepSeek Harness 的安装目录，按页面完成真实回复、来源回执与播放验证。AIRI 默认关闭；有需要再选择自己的 AIRI 安装目录并验证，不复制第二套 AIRI。
8. 需要音色包迁移时，单独安装音色包导入导出 `.avmodule`，然后从模块列表打开。未安装时本体没有该业务入口；首次配置也不要求安装该模块。

## 安装后的目录

所有 Python、TTS、FFmpeg、模型与应用数据均以当前 EXE 目录为根。环境模块安装时会重定位内置 GPT 的 Python 配置，不能依赖旧版路径、目录联接、用户级 pip 或开发机缓存。

```text
Agent语音/
  agent语音.exe
  assets/setup/                  随软件提供的独立配置网页
  runtime/core/                  主服务 Python
  tools/ffmpeg.exe
  tools/ffprobe.exe
  tools/system-prerequisites/    官方系统组件离线安装文件
  tts-engines/cosyvoice/{source,models,runtime}/
  tts-engines/gpt-sovits/{source,models,nltk_data,runtime}/
  modules/<id>/                  用户主动安装的功能模块
  trained-voices/                用户自己的训练输出
  data/                          本次安装新建的配置、日志及状态
```

## 验收与边界

检查发行根目录的清单、SHA-256、安装验收记录。安装成功只表示文件校验和落盘成功；声音生成、播放、Harness、AIRI 分别验证，不能相互代替。

本机模拟安装可以证明换目录后的独立运行，不能代替全新 Windows 或另一台 GPU 的验收。环境档位与实测显卡见本次发行清单。不要卸载开发机驱动、系统组件或修改全局 Python 来模拟“干净电脑”；新安装必须使用自己的运行环境与配置。

个人资产留存不属于发行内容，不要将其混入软件、环境、引擎或功能模块包。第三方引擎、权重与环境保留原有许可文件；模块化不免除录音、模型与依赖的授权义务。离线系统组件的官方说明：[WebView2](https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution)、[Visual C++](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist)。
