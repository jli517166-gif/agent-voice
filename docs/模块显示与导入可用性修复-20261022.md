# 模块显示与导入可用性修复

## 问题与修复

- 主程序模块列表动态生成的按钮没有应用主题，出现浅色背景与浅色文字。刷新列表后立即对新增控件应用当前主题。
- 可选模块缺少 DPI 声明，Windows 放大窗口位图，文字发糊。模块增加 DPI 感知与原生清晰绘制；布局在控件创建完成后统一缩放，最小窗口保留可见的声音列表。
- 导入只更新当前声音，没有保存为声音方案，控制台下拉框为空。模块现在在同一离线操作锁内完成导入、固定参考录音、保存方案及应用；用录音内容、模型指纹及声音参数识别同一声音，重复导入复用方案，保留用户改名。
- 空方案列表的“切换声音”使用异步 Action，异常越过同步按钮的错误处理。改用 Task 按钮，并对未选方案提供正常状态提示。控制台显示真实已应用的方案名称。
- 打开模块之前强制保存声音草稿，阻止空安装导入第一个声音。去掉该前置条件；导出仍读取主程序最后应用的配置。

可选模块版本为 **1.0.1**。本体仍不包含音色包归档实现，不附带声音或参考素材。已经用旧版导入的声音，可打开模块，填写名称后点击“保存当前声音”，再返回控制台。导入新文件会自动完成此步骤。
