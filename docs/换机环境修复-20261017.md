# 换机环境修复说明（2026-10-17）

旧版“补齐环境”只检查 Python 包、引擎源码、模型文件和 CUDA 导入，没有真正加载声音模型与生成音频。因此另一台电脑可能显示补齐成功，实际启动服务后仍不能发声。

本次修复把成功标准改为完整闭环：检查文件与依赖、检查 CUDA、加载所选模型、生成“环境补齐验证成功。”、校验生成的 WAV。任何一步失败都会显示原始错误和对应处理建议。验证音频保存在 `data/environment-repair/smoke/`。

程序还会识别新 NVIDIA 显卡与旧 PyTorch 内核不兼容的 `no kernel image` 错误，自动安装官方 PyTorch 2.7.1 CUDA 12.8 运行时并重新执行真实合成。显卡驱动、Microsoft Visual C++ 2015–2022 x64 运行库和 .NET Framework 属于 Windows 系统组件，程序会明确指出缺项，但不会静默声称已经修好。

## 给已有安装应用修复包

1. 关闭 Agent 语音服务和桌面程序。
2. 将修复包中的 `Agent语音` 文件夹覆盖到原软件目录；不要删除原目录，`data/settings.json` 和用户音色不会被覆盖。
3. 重新打开程序，进入“设置 → 系统维护 → 补齐环境”。
4. 选择“当前引擎与主服务”，点击“补齐缺失环境”。
5. 页面出现“真实合成”并显示绿色通过后，再启动服务试听。

如果仍未通过，打开 `data/environment-repair/latest.json` 和页面列出的日志。报告中的 `system`、`runtimeChecks` 与 `synthesisChecks` 可以直接定位失败发生在驱动、原生运行库、模型加载还是实际生成阶段。
