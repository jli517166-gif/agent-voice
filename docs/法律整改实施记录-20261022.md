## 仍需完成的外部核查与发行工作

1. **旧 FFmpeg 的精确构建源码、静态依赖与交付材料**；GPL／LGPL 库的实际组合和义务仍需完整核查，不能只补一份许可文字就结案。本轮未移除发音链必需依赖，也未替换实际 FFmpeg。
2. **GPT 各版本和附属模型、CosyVoice 子模型、CUDA／Microsoft 运行组件及未逐文件溯源素材的分发证据**。现有组件登记与文件清单不是完整依赖关系 SBOM；未确认项保持未确认，相关产物不标成发行许可通过。
3. `AgentVoice.local` 是本地软件身份，**不是登记的公众生成服务提供者编码**。当前不经营公网生成／陪伴服务；将来改变业务须重新确认适用规则及实际运营要求。实现文件布局和可见说明，不等于获得政府合规认证。
4. 官方来源证明流程已提供，但**本轮没有运行远端签名工作流**；私有仓库功能还受 GitHub 计划限制。当前模块候选包的公开分发证据检查为 false，不能称为已签名或已清权发行包。
5. 邮箱由所有者提供，未自动发信验证。真实投诉收件、权利判断、响应与专业复核需要维护者持续负责；软件无法验证合同或自然人同意的真实性。
6. 已有主工作区含未提交改动，**不覆盖 main、不强推历史**。本次成果留在 `integration/native-design-20261019` 并同步 GitHub；正式发布前仍需核对默认下载入口、源码标签、审查记录与成品。

这些不是被忽略后显示绿色的项目。工程检查会将它们明确留在清单中；本轮目标是落实控制、保留证据与阻止虚假发行通过，而不是承诺零法律风险。
