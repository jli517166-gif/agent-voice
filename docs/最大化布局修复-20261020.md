# 最大化布局修复 · 2026-10-20

本轮按用户确认，先修复 DeepSeek Harness 交接的最大化布局问题。工作区为 `E:\App\agent-voice-native-review`，分支为 `integration/native-design-20261019`，交接基线为 `ac704ac`。没有修改 TTS、Harness 接入协议、AIRI 桥接或配置动画方案，没有重新打包。

## 实际原因与处理

记录窗口、根容器和页面几何后，确认 `shell` 和 `outer` 在普通、大窗口、最大化、还原及最小尺寸下均铺满客户区，原交接中的 Dock 怀疑未得到证实。

1. 原 `WebFit` 将窗口尺寸变化再次作用于字体点数，与 Windows DPI 缩放叠加，最大化后文字膨胀并压住输入框。现在从每页首次布局捕获不可变坐标、字体和实际内容范围；坐标随可用空间变化，大窗口字体不重复放大，还原不累积缩放。较长子页使用自己的内容高度。
2. 侧栏另加的同级背景 Panel 覆盖导航。移除该遮挡层，改为布局容器本身绘制背景。
3. 工作台背景 PNG 中的卡片与真正控件使用不同缩放基准，产生双层、错位画布。响应页面使用实际控件绘制，不再叠加固定卡片截图；自定义图片继续保留。
4. 首页标题、长音色名和按钮的 AutoSize/MinimumSize 与手动尺寸冲突。明确文字区域和按钮边界，长音色名使用省略显示，正文输入区域与标题分开。
5. 自定义图片的双三次插值采样了图像边界外的透明像素。使用镜像边缘采样和覆盖客户区的目标矩形，消除边缘暗线。

没有新增遮罩。窗口、设置内容、模型与用户资产不依赖测试截图。
