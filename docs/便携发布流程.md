# 便携发布与清理

## 发布范围

当前便携包只内置 Fairy，沿用已试听的 CosyVoice 训练模型与参考条件；不对声音再次训练或添加变声。保留 CosyVoice、GPT-SoVITS v5 Turbo、ProPlus 三个 TTS 选择及各自运行资源。GPT 两个档位共用模型库。其他角色、RVC、个性外观、账号/连接凭据、聊天、缓存、生成音频、训练数据与旧版本不随包发布。

Fairy 完整训练模型在 `tts-engines/cosyvoice/models/Fairy-CosyVoice3`，配套参考在 `voices/Fairy`。便携版不同时复制一份相同的未训练基础模型；训练新角色时按训练手册单独准备官方基础模型。若附带 Fairy 音色归档，只保留一份带名称和 `.cosyvoice.ttsmodel` 后缀的轻量包，复用随包的训练模型。

`assets/bundled-voice.json` 仅含格式版本、音色名、公共 CosyVoice 参数。资源必须使用程序内相对路径；不接受私有资产、外部路径、密钥或连接设置。Python 服务与桌面端均仅在 `data/settings.json` 不存在时使用，已有设置始终优先，损坏设置仍报错而非静默重置。每套新安装生成自己的连接密钥。

GitHub 只保存源码、测试、适配器、构建/打包脚本及文档，不上传任何引擎运行副本、模型、声音归档或录音。包内上游许可证与运行时许可文件保留。

## 构建与暂存

先运行完整 Python 回归、Node 连接器回归与 Windows 编译。`build.ps1` 输出到一个新的 `build-*` 目录；它只构建软件，不复制本机用户数据。下列变量由维护者指定，`$voiceSpec` 为受审查的单个公共音色 JSON，不能直接传入 `data/settings.json`。

```powershell
python tools/package_portable.py stage `
  --build "$builtApp" --installation "$verifiedInstall" `
  --model "$fairyModel" --reference "$fairyReference" `
  --spec "$voiceSpec" --target "$newStagingDirectory" --commit "$verifiedCommit"
```

暂存目录必须不存在，禁止覆盖安装或旧文件。从安装仅复制固定的引擎源码、运行环境、GPT 公共模型与发音资源；CosyVoice 仅复制显式选定的 Fairy 模型。所有隐式 Windows 目录链接默认拒绝；GPT 不再依赖源码中指向原安装的预训练模型链接，G2PW 的已知内置链接经校验后物化为真实文件。库内合法的 `data` 资源保留；应用顶层 `data` 不进入归档。

在暂存路径完成以下实测，记录结果：

1. 无设置首次启动，桌面端与 Python 读取同一个 Fairy 默认；默认外观、新密钥、AIRI 关闭。
2. 三种 TTS 均在移动后的路径实际生成，确认实际引擎、版本、模型和非静音。使用独立端口，测试后关闭该验收实例，不影响日常服务。
3. Fairy 音色轻量包往返导入、重复导入复用资源；既有用户设置不被默认音色覆盖。
4. 桌面自检通过。Harness、MCP、AIRI 的代码和桥接组件保留；新电脑必须重新选择其安装目录并进行真实验证，不预置“已连接”。

## 归档与复验

用户确认发布后才执行：

```powershell
python tools/package_portable.py archive `
  --root "$newStagingDirectory" --output "$newZipPath" --accepted
```

目标文件不得存在。工具按允许目录生成逐文件清单，执行 `release_audit` 的资源、私有归档和用户数据检查；只把允许文件写入 Zip64，缓存与验收时生成的顶层设置不打包。压缩后完整读取归档校验 CRC，生成 SHA-256 与旁置 `.manifest.json`、`.audit.json`，未通过时不将 `.partial` 发布为成品。

在另外一个全新路径解压成品再检查默认音色、环境与实际生成；仅验证压缩工具成功不足以说明换目录可用。云端回归不代替 GPU、声卡或用户对声音的验收。

## 清理边界

先完成包的完整性和解压实测，再清理旧构建、废弃引擎环境、下载缓存、测试安装与过期备份。每个递归删除目标先规范化为绝对路径，核对位于明确的项目/验收/备份目录内；目录链接单独处理，不递归进入链接目标，不删除正在使用的环境。

保留正式安装、Git 历史、当前设置与声音方案、模型、参考录音、原始训练素材、最终试听、验收统计以及一份当前代码/配置恢复备份。不要根据扩展名批量删 `.pth`：Python 路径文件与 GPT TTS 权重均可能使用该后缀。唯一声音资产不是“垃圾”；不能确定用途的资产保留并记入报告。
