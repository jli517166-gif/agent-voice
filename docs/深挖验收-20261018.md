## 可确认的边界

- 软件上线不会绕过第三方登录状态。Codex CLI 已登录时可以全自动；DeepSeek 只有桌面账号时需要在桌面端发送一次随机验证短句，配置可供 headless 使用的 API Key 后才可全自动。
- AIRI 默认可以关闭；启用后必须打开已安装桥接的原 AIRI 并收到原生播放完成回执，心跳本身不算成功。
- 环境补齐只能在下载源、磁盘、驱动和硬件满足要求时完成；完成后仍以三种 TTS 的真实生成验收为准，不能只凭文件存在判定成功。
