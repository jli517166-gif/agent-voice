上述 Harness 检查是连接器所用事件接口与实际播放测试，不代表本轮重新执行了外部 Harness 的完整模型会话。AIRI 检查是音频 API，不代表本轮重新验收桌宠口型。不同电脑、驱动和外部程序版本仍需在目标机器做真实连接验证。
