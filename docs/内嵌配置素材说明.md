# 内嵌配置素材说明

`assets/setup/art/` 复用已经登记的公开配置原型素材。没有复制用户音色、参考录音或自定义背景。

- computer、folder、headphone、mic、tools、link、music、puzzle：Realvjy 的 [3dicons](https://3dicons.co/) 白色 clay 素材，原下载页登记为 CC0。来源与 SHA-256 见 `docs/design-review/20261019-black-white-stage/web-materials.json`。
- airi-11-icon.png：本机原 AIRI 的公开应用图标，[AIRI](https://github.com/moeru-ai/airi) 项目为 MIT；原型登记信息在该目录的 `airi-asset-inventory.json`。
- airi-scene.png：复用 `assets/onboarding/step-8.png` 中已经采用的 AIRI 场景。该场景来自先前原型与构图素材，保留粉色，页面外围统一为石墨黑。
- 界面短音：复用 `assets/sfx/step-0.wav` 至 `step-8.wav`，与 TTS 输出无关。关闭音效、测试模式或服务运行时不播放。

白底图像未改写像素，通过 CSS 混合与等比缩放融入背景。各页素材有不同的有限动作；标题先于素材强调内容，减少动画与缩放暂停对所有页生效。素材动作不代表真实配置进度。

## 2026-10-21 透明素材修订

当前页面使用 `assets/setup/art/cutouts/` 中的七张原作者透明 PNG，不再用白底 WebP 的反色混合。来源、许可、SHA-256 和尺寸保存在该目录的 `sources.json`。官方来源为 [Realvjy/3dicons](https://github.com/realvjy/3dicons)，CC0-1.0。环境页采用拼图表示依赖装配。图像均核验 RGBA、透明及不透明像素范围；未用代码抠图或改写像素。

曾尝试内置 imagegen 的四图抠图，出现边缘残留，未采用，也未将该生成结果加入项目。改用原作者原生透明素材，避免再对图片轮廓作近似处理。AIRI 直接使用原图标配合 CSS 曲面舞台和 SVG 声浪，不使用 `airi-scene.png` 配置截图作为界面。
