# 内嵌网页配置实现与验收 · 2026-10-21

## 本轮交付

独立首次配置改为软件内嵌 WebView2，十页本地 HTML/CSS/JS 随软件保存，不再依赖 51270 原型服务器或在线 CDN。网页只负责展示和输入；C# 白名单控制器调用既有 SetupWorkflow、模块事务安装、声音导入、服务 API、ConnectionSetup 的真实实现。

保留开场、电脑、选择引擎、准备引擎文件、补齐环境、选择音色、试听、Harness、AIRI、回顾。配置可跳过、稍后继续；Next 保存所选引擎，Skip 不应用未确认选择。参数与文件路径可在抽屉编辑，文档、原生文件选择器与实际任务日志可访问。只有当前页元素参与动画，标题先出现，各页素材使用不同的有限动作；缩放暂停动画，支持减少动画与音效关闭。AIRI 保留粉色场景，默认是否启用遵循用户现有设置，新配置默认关闭。

本地虚拟源为 `https://setup.agent-voice.local`。拒绝其他导航和新窗口，消息校验来源、长度、请求编号与命令；不向网页发送服务 token，不提供任意命令执行。页面使用 CSP、本地资源与动态文本转义。

缺少 UI 运行时提供微软联网安装、离线安装器、固定版导入、简洁原生配置和稍后入口；缺少 SDK DLL 则直接回退原生配置。微软签名在执行前验证，固定版暂存成功后再提交，安装器真实退出前保持写入保护。WebView2 SDK 固定为 1.0.3537.50，NuGet SHA-256 为 `5EA526BBD728ADDA0DA4D31219267E96460494A427E4894C4E09D9F320F4B9AA`，缓存到忽略目录 `.build-deps`。

## 修复的边界问题

- 缺少 SDK 不再延迟到异步初始化或释放时崩溃。
- 配置显示不依赖语音服务健康；端口是其他服务也能进入配置并查看错误。
- 初始化与实际任务互斥；重复点击和中途关闭不能启动第二次写入。
- 停止试听贯穿服务启动、模型加载、提交与播放轮询，取消后不再迟到提交声音。
- 提交后轮询失败会清理待试听；停止失败保留待处理状态，退出或继续配置前必须重试。
- 取消启动后关闭，会清理本窗口 Owned 的服务进程；原本已经运行的服务不因简单关闭而退出。
- 固定版复制失败不会留下被误选的正式半成品，重新导入可重试。
- 配置偏好原子替换遇到短暂占用会有限重试；持续占用仍报错并保留旧文件。
- 普通切页不残留任务等待提示卡；Python 协议测试只读取隔离的空 Codex 会话，避免被实时聊天污染。

独立代码审查与复核已执行。缺 SDK 的工厂回退用隔离 EXE 实测返回 SetupWizard 并正常释放；其余最终静态复核没有新的重要遗漏。关闭停止重试的单元回归调用共用清理方法，未冒称已模拟系统级强制终止。
