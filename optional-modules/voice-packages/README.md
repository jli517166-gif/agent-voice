# 音色包模块 · 可选扩展 1.2.0

私用安装默认装载。从「模块」打开，导入后应用声音并登记到声音方案；导出直接选择文件，不再弹出公开版的授权确认，也不附加素材许可摘要。旧包仍可读取。

| 类型 | 包含内容 | 导入条件 |
|---|---|---|
| 轻量包 | 推理参考录音、逐字台词、参数 | 已有匹配的基础模型、源码与环境 |
| 模型完整包 | 上述内容与当前模型权重 | 有对应引擎源码与环境 |
| 高级训练包 | 参考、参数与训练后变更的权重 | 已有完全匹配的基础模型 |
| 高级完整包 | 参考、参数与完整训练模型 | 有对应引擎源码与环境 |

后缀仍为 `.cosyvoice.ttsmodel` 或 `.gpt-sovits.ttsmodel`。哈希、路径安全、模型兼容、事务回滚、参考去重和损坏检查保留。模型不随本模块重复装入。

本模块独立构建并按需安装；软件本体不附带该模块、录音或模型。第三方许可文件保留。
