# 音色包导入导出 · 可选模块

软件本体不包含此模块的程序、Python 后端或默认音色，也不在首次配置中导入音色包。只有手动安装模块后，模块页才会显示打开入口。模块自身不携带参考录音、台词或模型权重。

安装：主程序 → 模块 → 导入模块 → 选择 `.avmodule` → 核对来源并安装 → 打开模块。安装模块不要求 Python；进行音色包导入导出时需要主程序已补齐的主服务 Python 和对应引擎。移除：模块页 → 移除模块；保留用户模型和录音，模块实现移入恢复备份，主程序不再发现或启动它。

| 类型 | 内容 | 目标电脑要求 |
|---|---|---|
| 轻量包 | 参考录音、台词、参数、模型及环境指纹 | 相同基础模型及兼容引擎环境 |
| 模型完整包 | 上述内容及当前模型权重 | 已适配的引擎和兼容环境 |
| 高级训练包 | 参考条件及相对基础模型改变的训练权重 | 相同 CosyVoice 基础模型及兼容环境 |
| 高级完整包 | 完整训练模型及参考条件 | CosyVoice 引擎及兼容环境 |

CosyVoice 支持四种类型，GPT-SoVITS 支持前两种。文件名包含自定义名称和 `.cosyvoice.ttsmodel` 或 `.gpt-sovits.ttsmodel`，导入时校验兼容性并恢复对应版本。Python、TTS 源码及整套运行环境不随音色包重复打包。

先在主程序应用模型与参考录音，再打开模块导出。服务有正在执行或等待的朗读任务时，操作会拒绝；空闲服务会暂时停止，文件操作结束后尝试恢复，恢复失败会明确提示。导入不改变 Harness 连接开关和控制凭据。

本模块是独立本地程序，通过 `--root` 获取主程序目录；不注入主程序，不接管首次配置。后端位于模块自身 `backend/`，只借用本体的本地模型校验、状态和离线操作锁。删除模块后，核心朗读和保存声音方案仍可工作。

构建先执行仓库根 `build.ps1` 构建本体，再执行本目录 `build.ps1 -CoreBuild <本体构建目录> -OutputDirectory <独立模块暂存目录> -Package <新文件.avmodule>`。模块源码与本体同库维护，但根构建不会编译或复制本目录。

权限提示：导入模块等同于允许运行本地代码，仅安装可信来源模块。文件 SHA-256 证明完整性，不证明发布者身份。模块拆分不授予录音、人物声音、训练数据或模型的使用／传播权；使用和分享者仍需确认授权。
